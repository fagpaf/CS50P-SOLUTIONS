# CS50P — Introduction to Programming with Python

Repositório dedicado às soluções dos exercícios e problem sets
desenvolvidos durante o curso CS50's Introduction to Programming
with Python, oferecido pela Harvard University.

## Sobre o curso

O CS50P aborda os fundamentos da programação utilizando Python,
incluindo funções, estruturas de controle, tratamento de exceções,
testes unitários, manipulação de arquivos e orientação a objetos.

## Conteúdos estudados

- Functions and Variables
- Conditionals
- Loops
- Exceptions
- Libraries
- Unit Tests
- File I/O
- Regular Expressions
- Object-Oriented Programming

## Tecnologias

- Python
- pytest
- Git e GitHub

## Objetivo

Documentar meu aprendizado em Python e manter um registro dos
problemas resolvidos ao longo do curso.
